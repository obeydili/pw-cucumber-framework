# pw-cucumber-framework

My Playwright + TypeScript + cucumber-js test framework, built task by task with the Muallim in the QA Co-Pilot Hub (Workbench → Local workspace).

## What's here so far

- `practice-app/`: **Trade Desk Lite**, the fake app under test. See `practice-app/README.md` for users, pages and the API.
- `.muallim/`: notes for the Hub (see the README inside).

Everything else (`package.json`, `features/`, `src/`, `env/`, `cucumber.js`, `Makefile`, CI) is mine to build, starting with Task T01.

> This README is a starting point. Task T21 asks me to rewrite it so someone new could run the suite from it.
